# Source Quality

Prefer these sources in order:

1. Primary project or package documentation.
2. Peer-reviewed papers, arXiv papers with clear methods, benchmark cards, or official reports.
3. Source repositories, release notes, issue discussions, and implementation examples.
4. Reputable technical writeups that cite primary sources.
5. Forum posts or informal examples only when they explain a concrete failure mode.

When using a weaker source, state why it is still useful and what evidence would
confirm or refute it locally.
