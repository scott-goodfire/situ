# Analysis Output Contract

For source-backed web research, the `Analysis.content` should be structured enough
for the Manager and Scientist to use without redoing the search:

```text
Search scope:
- ...

Sources:
- Source name: URL
- Source name: URL

Synthesis:
- ...

Implications for this project:
- ...

Candidate hypotheses:
- ...

Uncertainties:
- ...
```

Do not create hypotheses just because sources were found. Create a hypothesis only
when the claim is testable and useful for a future Scientist experiment.
