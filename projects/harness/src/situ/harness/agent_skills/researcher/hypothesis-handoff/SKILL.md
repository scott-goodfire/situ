# Hypothesis Handoff

## Method

1. Read the task and relevant analyses.
2. Create only hypotheses that can guide a concrete experiment.
3. State the expected direction and why the analysis supports it.
4. Mention the measurement evidence a Scientist should collect.
5. Link the task to the hypothesis and any supporting analysis.

## Good Hypothesis Shape

- Title: short testable claim.
- Summary: mechanism, expected metric direction, and local change surface.
- Status: active when ready for Scientist work.

Do not use hypotheses as generic notes. Keep broad synthesis in `Analysis`.
