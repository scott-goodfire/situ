# Interpret Task

## Method

1. Load `task-execution`.
2. Read the assigned task, project board, and focused lists for the relevant analyses, hypotheses, experiments, evaluations, measurements, reviews, and artifacts.
3. Compare evidence against the objective and measurement constraints.
4. Create or update an `Analysis` with the interpretation.
5. Link the task to the interpreted records and the produced Analysis.
6. Add comments to hypotheses or analyses only when they clarify durable research judgment.
7. Mark the task done with the recommended next task or blocker.

## Interpretation Bar

- Separate measured results from possible explanations.
- Name comparability concerns, missing evidence, or suspicious results.
- Do not call a candidate successful until recorded measurement evidence supports it.
- Prefer a concrete next task over a broad recommendation.
