# Prior-Art Synthesis

## Method

1. Load `source-grounding` when source quality matters.
2. Search for public context only after reading the task and project board.
3. Group sources by idea, not by search query.
4. Translate external ideas into local constraints and possible experiment knobs.
5. Record synthesis as `Analysis`; create hypotheses only for testable local claims.

## Avoid

- Treating a paper result as automatically true for this workspace.
- Creating generic hypotheses that do not point to a local change.
- Losing URLs or source names.
- Ignoring local evaluation constraints.
