# Agent Instructions

## Concurrent Changes

If the worktree changes underneath you while you are working, stop and reassess
before making more edits. When the correct integration path is not clear, do not
patch around the concurrent change. Leave the worktree as-is, report what
changed, and ask for direction.

Only continue without asking when the fix is obvious, tightly scoped, and does
not overwrite or reinterpret someone else's edits.
